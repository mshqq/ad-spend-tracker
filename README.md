# Ad Spend Tracker

Учебный сервис учёта расходов на рекламные кампании на Python и Django.

Пользователь может зарегистрироваться, создавать рекламные кампании,
задавать бюджеты и вести расходы. Кампании и расходы доступны только владельцу.
Доступны просмотр, изменение и удаление с подтверждением.
Кампании можно фильтровать по статусу, расходы — по диапазону дат включительно.
Фильтр дат меняет только список расходов: итоги бюджета считаются за всё время.

Все суммы учитываются в рублях с точностью до копеек. Превышать бюджет
разрешено: сервис показывает предупреждение и отрицательный остаток.
Удаление кампании удаляет все её расходы.

## Требования

- Python 3.12 (версия закреплена в `.python-version`).
- Установленный [uv](https://docs.astral.sh/uv/getting-started/installation/).
- Git для работы с репозиторием.

Используются Django 5.2 LTS и SQLite. Отдельный сервер базы данных не нужен.

## Локальная установка

В терминале перейдите в корень проекта — папку с `manage.py`.
Все команды ниже выполняются из неё.

Установите зависимости из `uv.lock`:

```bash
uv sync --locked
```

uv создаст окружение `.venv` и при необходимости скачает Python 3.12.
Активировать окружение вручную не требуется: команды запускаются через `uv run`.

Создайте таблицы базы данных:

```bash
uv run python manage.py migrate
```

Будет создан локальный файл `db.sqlite3`. Он исключён из Git.

Создайте пользователя для админки:

```bash
uv run python manage.py createsuperuser
```

Введите имя пользователя, email (можно оставить пустым) и пароль.
При вводе пароля символы не отображаются — это нормально.

## Запуск

```bash
uv run python manage.py runserver
```

- Список своих кампаний: <http://127.0.0.1:8000/> (требуется вход).
- Регистрация: <http://127.0.0.1:8000/accounts/signup/>.
- Админка: <http://127.0.0.1:8000/admin/>.

Для входа в админку используйте данные созданного суперпользователя.
В ней доступны пользователи, группы, кампании и расходы.
Остановить сервер можно сочетанием `Ctrl+C`.

Настройки пока предназначены для локальной разработки: включён `DEBUG`,
используется открытый ключ для разработки. Перед публикацией потребуются
отдельные настройки и секретный ключ из переменных окружения.

## Проверка проекта

Проверка настроек:

```bash
uv run python manage.py check
```

Проверка, что изменения моделей не требуют новых миграций:

```bash
uv run python manage.py makemigrations --check --dry-run
```

Запуск тестов (pytest и pytest-django устанавливаются командой `uv sync --locked`):

```bash
uv run pytest
```

Тесты используют отдельную временную базу и не меняют локальные данные.

## Структура

```text
campaigns/       Приложение для будущих кампаний и расходов
config/         Настройки проекта, маршруты, WSGI и ASGI
manage.py       Команды управления Django
pyproject.toml  Зависимости и требования к Python
uv.lock         Зафиксированные версии зависимостей
```
